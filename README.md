# バス時刻表テンプレート(仮称)

路線バス・コミュニティバス・送迎バスなど、小さなバスの**時刻表サイトを、データを書くだけで作って公開できる**テンプレートです。
[ビビバス](https://bibi-bus.com/)(千歳市の路線バス「美々空港線」の非公式時刻表)の画面・操作感を引き継ぎ、千歳固有の部分をデータに切り出しました。

- 乗車地・降車地を選ぶと、**このあとの便**をカウントダウン付きで表示(深夜0時またぎの便にも対応)
- **時限(1限〜7限など)に間に合う便**の検索。学校の時間割やシフトなどで使えます(任意。時限の数・時刻は自由、使わないなら非表示)
- 平日 / 土日祝、**長期休業期間**での運休・休業中専用便、ダイヤ改正日に対応
- 時刻表の一覧(**表示するバス停は利用者が選べる**)と、便ごとの停車バス停の一覧
- お知らせタブ(運休・ダイヤ変更の連絡用)
- 運行会社・路線の種別は、データに書いたときだけ画面に出る
- サーバー不要の静的サイト。GitHub Pages に**無料**で公開できる。スマホ向け、ダークモード対応

---

## 作り方

必要なものは **GitHub のアカウント**だけです。やり方は2つあります。

| | A. ブラウザだけで作る | B. 自分のパソコンで作る |
|---|---|---|
| 向いている人 | まず試したい。小さな修正だけ | Excel/CSV で一括入力したい。見た目も変えたい |
| インストール | 不要 | Node.js が必要 |
| 時刻の入力 | GitHub の画面で JSON を編集 | Excel/CSV から取り込める |

どちらでも、最後の**「公開する」(下の手順)**は同じです。

### 共通の最初の手順: 自分のリポジトリを作る

1. このページ右上の **「Use this template」→「Create a new repository」**(テンプレートでなければ **Fork**)を押します。
2. リポジトリ名(例: `my-bus`)を決めて作成します。**Public(公開)**のままにしてください(無料の GitHub Pages は公開リポジトリが前提です)。

### 公開する(GitHub Pages)

作ったリポジトリで、次の順に進めます。

1. 上のタブ **「Actions」** を開きます。「Workflows aren't being run on this forked repository」のような表示が出たら、**「I understand my workflows, go ahead and enable them」**を押して有効にします。
2. **「Settings」→ 左メニュー「Pages」**を開き、**「Build and deployment」の「Source」を「GitHub Actions」**に変えます(自動で保存されます)。
3. 「Actions」タブに戻り、左の **「Deploy to GitHub Pages」→「Run workflow」** を押して、1回動かします。(次からは、`main` に変更を保存するたびに自動で動きます。)
4. 実行が **緑のチェック(成功)** になるまで、1〜3分待ちます。
5. 公開URLは **`https://<あなたのユーザー名>.github.io/<リポジトリ名>/`** です。もう一度 **Settings → Pages** を開くと、上部にURLが表示されています。

> **赤い×(失敗)になったら**
> 実行のログを開き、**`validate`** の行を見てください。データの書き間違いがあると、公開は止まります(間違ったまま公開しないための仕組みです)。「どのファイルの何が悪いか」が日本語で書いてあります。直して保存すると、自動でやり直されます。

独自ドメインやサブパスでも、そのまま動きます(URLが `#/timetable` の形なので、サーバー側の設定は要りません)。

### A. ブラウザだけで時刻表を書き換える

1. リポジトリの `public/data/` を開きます。4つのファイルがあります。

   | ファイル | 中身 |
   |---|---|
   | `site.json` | サイト名、方向(下り・上りなど)、時限、休業期間、お知らせ |
   | `stops.json` | 停留所 |
   | `routes.json` | 路線と、停車する順番 |
   | `trips.json` | 便ごとの時刻 |

2. ファイルを開き、右上の**鉛筆のアイコン(Edit)**を押して書き換え、**「Commit changes」**で保存します。
3. 自動で検査と公開が走ります(上の「公開する」の手順4と同じ)。数分後にサイトへ反映されます。

書き方は [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)。最初は付いているサンプルの文字を、自分の路線に置き換えていくのが簡単です。`examples/sample/` に、同じサンプルの控えがあります。

> 便の数が多いときは、JSON を手で書くのは大変です。**B(CSV の取り込み)**をおすすめします。

### B. 自分のパソコンで作る

#### 1. Node.js を入れる(初回だけ)

Node.js は、このテンプレートの検査やビルドを動かすための道具です。

1. <https://nodejs.org/ja> を開き、**LTS**(推奨版)をダウンロードして、インストーラーの指示どおりに進めます。バージョンは **22**(20以上なら動きます)。
2. ターミナルを開きます。
   - Windows: スタートメニューで「PowerShell」または「ターミナル」を検索して開く
   - Mac: 「ターミナル」アプリを開く
3. 次を入れて、バージョン番号(例: `v22.12.0`)が出ればOKです。

   ```bash
   node -v
   ```

#### 2. リポジトリを自分のパソコンに取り込む

「Code」ボタンの URL を使います。[Git](https://git-scm.com/) か [GitHub Desktop](https://desktop.github.com/) を使うのが簡単です。

```bash
git clone https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
cd <リポジトリ名>
npm install
```

`npm install` は、必要な部品をダウンロードします(初回は1〜2分かかります)。

#### 3. 時刻表を書く

**Excel / スプレッドシートで書く(おすすめ)**: `timetable-csv/` の表を書き換えます。書き方は [docs/CSV_FORMAT.md](docs/CSV_FORMAT.md)。書き換えたら、取り込みます。

```bash
npm run import
```

JSON を直接書く場合は、`public/data/` の4ファイルを編集します(上のAと同じ)。書き方は [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)。

サイト名・方向・時限・休業期間・お知らせは、`public/data/site.json` で設定します。

#### 4. 入力ミスを確認する

```bash
npm run validate
```

`OK: 停留所…` と出れば問題ありません。エラーが出たときは、その内容どおりに直してください。

#### 5. 画面を確認する

```bash
npm run dev
```

ブラウザで <http://localhost:3000> を開くと、自分のパソコンの中だけで表示を確認できます。止めるときは、ターミナルで `Ctrl + C` を押します。

> `npm run dev` は、同じネットワーク(同じWi-Fiなど)の他の端末からも見える状態で起動します。公共のWi-Fiでは、使い終わったら止めてください。

#### 6. 公開する

変更を GitHub に送ります。

```bash
git add .
git commit -m "時刻表を更新"
git push
```

あとは、上の**「公開する(GitHub Pages)」**のとおりです。送るたびに、自動で検査して公開します。

## 学期ごとの更新

- ダイヤが変わったら、便を差し替え、古い便に `until`(この日まで)、新しい便に `from`(この日から)を付けます。過去の日付を見たときも正しく出ます。
- 休業期間は `site.json` の `calendar.breaks` を書き換えます。
- 運休・変更の連絡は `site.json` の `notices` に1件足すと、「お知らせ」タブに出ます。

## 見た目を変える(開発者向け)

画面の細かい調整はコードで行います。データだけで公開する人は触らなくて大丈夫です。

- **色**: 主な強調色は `src/index.css` の「テーマカラー」のコメントを外して値を変えます。バッジの色名は `src/lib/palette.ts`。
- **文言・レイアウト**: `src/pages/Home.tsx`(検索)、`src/pages/Timetable.tsx`(時刻表)、`src/components/`(ヘッダー・下部ナビ)。
- **アイコン・名前**: `public/favicon.svg`、`public/manifest.json`(ホーム画面に追加したときの名前と色)、`index.html`(説明文)。

## 構成

```
timetable-csv/   時刻表の表(ExcelやCSV。npm run import で public/data に取り込む)
public/data/     時刻表のデータ(JSON。サイトに表示される)
examples/        サンプル(sample: 汎用 / chitose: ビビバスの実データ)
docs/            データ形式とCSV形式の説明
src/lib/logic.ts 便の判定ロジック(平日・休業期・時限・深夜など)
src/pages/       ホーム(検索)と時刻表の画面
scripts/         データの検査(validate)・CSV取り込み・テスト
```

## 開発用コマンド

```bash
npm run lint         # 型チェック
npm test             # サンプル・実データの検査 + ロジック・CSV取り込みのテスト
npm run import       # timetable-csv/ → public/data/ に取り込み(検査つき)
npm run export-csv   # public/data/ → timetable-csv/ に書き出し
npm run build        # 検査 → ビルド(dist/)
```
