# examples/chitose — 千歳市の路線バス「美々空港線」(ビビバスのデータの控え)

このフォルダは、実在の路線のデータを使った**実用例**です。データの形式や、深夜0時またぎ・休業期間・ダイヤ改正日・複数の系統の書き方を確かめるために置いています。

千歳駅前・南千歳駅・新千歳空港・科技大・ラピダス前などを結ぶ、千歳市内の路線バスの系統を収めています(直通・空港経由・長都・南千歳の4系統)。

## 必ずお読みください

- **非公式です。** バス事業者、千歳市、沿線の施設とは関係がありません。これらの公式の案内ではありません。
- **現行のダイヤとは限りません。** 2026年10月時点で作ったデータの控えで、その後の改正や臨時ダイヤは反映されていません。更新も保証しません。
- **このデータを、そのまま乗車の判断に使わないでください。** 実際の運行は、必ず事業者・千歳市の公式の案内で確認してください。誤りによる損害について、作者は責任を負いません(README の免責事項を参照)。
- **ライセンスの対象外です。** リポジトリ全体のライセンス(MIT)は、このフォルダの時刻表データ・停留所名・路線名には及びません。再利用するときは、元の資料の利用条件を自分で確認してください。

## 出典

千歳市が公表した、2026年10月1日のダイヤ改正に関する資料(全停留所版の時刻表、バスのりば案内)を元に作成しました。取得日は記録していません(2026年10月時点)。資料の具体的なURLは、このリポジトリには載せていません。

## 内容

| ファイル | 中身 |
|---|---|
| `site.json` | サイト名、方向、時限(1〜5限)、休業期間、時刻表に出す列 |
| `stops.json` | 停留所20か所(のりば、「南千歳駅/OA入口」のような仮想の停留所を含む) |
| `routes.json` | 4路線(直通・空港経由・長都・南千歳)と停車順 |
| `trips.json` | 216便(平日・土日祝、休業中のみ運行する便、改正前後の便) |

汎用の小さなサンプルは [`../sample`](../sample) です。
