# ExcelやCSVで時刻表を入れる

`trips.json` を直接書く代わりに、**紙の時刻表と同じ見た目の表**をExcelやGoogleスプレッドシートで作り、CSVにして取り込めます。
JSONが苦手な人は、こちらがおすすめです。

```bash
npm run import      # timetable-csv/ のCSV → public/data/ の trips.json など
```

取り込み後に自動で入力チェックも行い、問題があれば「どのファイルの何行目か」を表示します。

## 雛形から始める

[`templates/template.csv`](../templates/template.csv) が、書き込み用の雛形です(説明の行つき)。

1. `templates/template.csv` を `timetable-csv/` にコピーし、ファイル名を分かりやすく変えます(例: `A_平日_下り.csv`)。
2. Excelなどで開き、`#route` `#direction` `#days` と、停留所・時刻を自分の路線に書き換えます。`#memo` の行は説明用なので、消しても残しても構いません。
3. 平日・土日祝・方向ごとに、1枚ずつ表を作ります(雛形をコピーして増やします)。
4. `npm run import` で取り込みます。

`timetable-csv/` に最初から入っているCSVは、サンプルのデータです。自分の路線を入れるときは、消してから取り込んでください。

自分の路線に入れ替えたあとは、次の2点を確認してください(`npm run import` が教えてくれます)。

- **`site.json` の `defaults`**(最初に選ばれる乗車地・降車地)を、新しい停留所の名前に書き換える。便が無い区間のままだと、エラーになります。
- **使われなくなった古い停留所**は、`stops.json` から消して構いません。便の無い方向(例: 片方向だけのCSVにした場合)は、`site.json` の `directions` からも消すと、画面がすっきりします。

## 1ファイル = 路線・方向・曜日ごとの1枚の表

`timetable-csv/` に、次のようなCSVを置きます(ファイル名は自由。便のIDはファイル名から自動で付きます)。

```
#route,A
#direction,down
#days,weekday
停留所,1,2,3
駅前,07:00,07:40,08:20
町役場前,07:05,07:45,08:25
市立病院前,07:09,07:49,
中央公園前,07:15,07:55,08:35
営業所前,07:18,07:58,08:38
```

- **行 = 停留所、列 = 便**です。上から下が停車する順になります。
- 停まらない停留所は、**空欄**か `|` や `-` にします(上の3便目は市立病院前に停まりません)。
- 時刻は `7:05` `07:05` `7:05:00` `7時5分` のどれでも読めます。深夜は `24:10` と書けます。Excelが時刻として扱っても大丈夫です。
- 表の1行目(`停留所,1,2,3`)は見出しです。便の名前や番号を自由に書けます(読み取りには使いません)。

### 表の上の `#` の行(この表全体の設定)

| 行 | 内容 | 例 |
|---|---|---|
| `#route` | 路線(`routes.json` のIDまたは名前) | `#route,A` |
| `#direction` | 方向(`site.json` の方向のIDまたは「下り」などの名前) | `#direction,down` / `#direction,下り` |
| `#days` | `平日` / `土日祝` / `毎日`(土曜を分けるなら `土曜`)。省略は毎日 | `#days,平日` |
| `#breaks` | 休業期間中の扱い: `通常` / `運休` / `休業中のみ`。省略は通常 | `#breaks,運休` |
| `#from` / `#until` | この日以降 / この日までだけ運行(ダイヤ改正用) | `#from,2026-10-01` |

`#route` と `#direction` は必須です。英語の値(`weekday` `holiday` `suspend` `only`)も使えます。

### 便ごとの設定(`@` の行・必要なときだけ)

運行会社や補足が便ごとに違うときは、表の上に `@` の行を足します。**列の順番が便の順番に対応**します。

```
#route,A
#direction,down
@operator,hokuto,sogo,hokuto
@label,,臨時,
停留所,1,2,3
...
```

運行会社(`@operator`)は `site.json` の `operators` のIDです。

## Excelでの作り方

1. 上のような表を作ります(A1セルに `#route`、B1セルに `A` のように入力)。
2. 「名前を付けて保存」→ **CSV UTF-8(コンマ区切り)** を選び、`timetable-csv/` に保存します。
   「CSV(コンマ区切り)」(日本語WindowsのShift_JIS)でも読めます。
3. `npm run import` を実行します。

Googleスプレッドシートなら「ファイル → ダウンロード → カンマ区切りの値(.csv)」です。

## 停留所・路線の扱い

- 停留所は**名前**で `stops.json` と突き合わせます。まだ無い名前は、その名前のまま新しい停留所として追加されます(のりばなどを付けたいときは、あとで `stops.json` を編集)。
- 路線も、`routes.json` に無ければ新しく作られます(名前と色は `routes.json` で直せます)。
- **停留所の並び**は、CSVの上から下の順で決まります。同じ路線・方向のCSVが複数あるときは、順番を守ったまま統合されます(食い違うとエラー)。
- `site.json`(方向・時限・休業期間・お知らせなど)は、CSVでは変わりません。

## 注意

- `npm run import` は **`trips.json` をCSVの内容で置き換えます**。CSVで運用すると決めたら、便の追加・修正はCSVだけで行ってください(JSONを手で直しても、次の取り込みで消えます)。
- すでにJSONで作ってある場合は、`npm run export-csv` でCSVに書き出せます(最初の `timetable-csv/` もこれで作っています)。`breakTimes`(休業中だけ使う別の時刻)はCSVでは表せないので、書き出されません。
